# BOM Price Parser — карта проекта

Автопоиск цен на ЭКБ: письмо с BOM → парсер → API дистрибьюторов → ответ письмом.
Этот файл — только маршрутизатор. Детали читать в целевых файлах, а не здесь.

## Куда смотреть

| Нужно | Файл |

| CLI-контракт парсера, флаги, окружение | `AGENTS.md` |

| Ключи API и флаги поведения | `.env` (не в git) |

## Команды

```bash
python price_parser.py --input "запрос.xlsx" --output "итог.xlsx" --yes
python price_parser.py --once <PN> <QTY> --manufacturer <бренд> --yes
PYTHONPATH=. python -m unittest tests.test_price_parser
```

Монитор: `START_MAIL.bat` / `STOP_MAIL.bat`; автозапуск: `INSTALL_AUTOSTART.bat` / `UNINSTALL_AUTOSTART.bat`.

## Что важно знать

- Запускать монитор **одним** способом (руками ИЛИ автозапуск) — два экземпляра дерутся за ящик.
- `mail-state.json` — отметки обработанных писем. **Не удалять**: иначе повторные ответы клиентам.
- Цена берётся **только** из API дистрибьютора. LLM-контур предлагает написание артикула, но
  строка заполняется лишь после подтверждения через API — цену модель дать не может.
- `HOLD_ON_RFQ` в `.env`: `false` — полный автомат; `true` — придержать ответ при остатке RFQ.
- Позиции, добытые LLM-контуром, красятся персиковым и считаются в сноске итогового xlsx.
