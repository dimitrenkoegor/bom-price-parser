# Инструкция для агентов (Codex и др.)

Этот репозиторий — инструмент поиска цен на электронные компоненты (ЭКБ) по BOM-файлам
через официальные API дистрибьюторов: DigiKey, Mouser, TME, Newark/Farnell.

## Главная команда

```bash
python price_parser.py --input "<запрос.xlsx>" --output "final/<имя_результата>.xlsx" --yes
```

- `--input` — Excel-запрос (шапка и колонки распознаются автоматически: Наименование /
  Условное обозначение / Количество / Производитель). Поддерживается и `.txt`
  (строки `PARTNUMBER QTY`).
- `--output` — путь итогового файла (по умолчанию `final/BOM_Приложение_1.xlsx`).
- `--yes` — ОБЯЗАТЕЛЕН для агентов: пропускает интерактивное подтверждение превью
  (без него скрипт остановится на `input()` и зависнет).
- Проверка одной позиции: `python price_parser.py --once <PN> <QTY> --manufacturer <бренд> --yes`
- Курс вручную: `--rub-rate 80 --rub-markup 4`

## Что скрипт делает

1. Распознаёт позиции из Excel (пишет превью `превью_позиции.xlsx` — при `--yes` не ждёт правок).
   Если ячейка содержит составную строку `тип изделия + MPN + бренд`, перед поиском
   отделяет русское название изделия и бренд. Запятые, `/`, дефисы и односимвольные
   префиксы `Q`/`O` внутри MPN сохраняются. Кириллические единицы в описании
   нормализуются (`КОМ` → `K`, `КГЦ` → `kHz`), но реальные отечественные MPN не
   латинизируются.
2. Ищет цены по всем 4 API, выбирает: приоритет — сток ≥ количества («In stock»),
   затем минимальная цена при ценовом брекете ≥ количества.
   Результат API принимается только при совпадении MPN и производителя из запроса;
   отсутствие производителя означает RFQ, а не подбор аналога.
3. Пишет стилизованный xlsx (10 колонок: Part Number | Distributor PN | Qty | Manufacturer |
   Distributor | MOQ | Stock | Lead Time | Unit Price USD | Unit Price RUB).
   RUB = USD × (курс ЦБ + наценка, по умолчанию +4).
4. stdout-итог: `Найдено: N | RFQ: M` и путь к файлу — парсить их для отчёта.

## Требования окружения

- Python 3.x + `openpyxl` (`pip install openpyxl`).
- Файл `.env` рядом со скриптом с ключами API (в git НЕ хранится, лежит только на рабочей машине):
  `MOUSER_API_KEY`, `DIGIKEY_CLIENT_ID`, `DIGIKEY_CLIENT_SECRET`,
  `TME_APP_SECRET`, `TME_TOKEN`, `FARNELL_API_KEY`.
  Без ключей скрипт не упадёт, но все позиции уйдут в RFQ.
- Интернет-доступ к `api.digikey.com`, `api.mouser.com`, `api.tme.eu`,
  `api.element14.com`, `www.cbr.ru` (курс), `open.er-api.com`.

## Правила предметной области (кратко из РЕГЛАМЕНТ_для_ИИ.md)

- Только авторизованные крупные дистрибьюторы (DigiKey, Mouser, TME, Newark/Farnell,
  Arrow, TTI, Avnet и аналогичные франчайзинговые) — API-версия уже это гарантирует.
- Аналоги с другими характеристиками запрещены; допустимы только отличия
  в суффиксе упаковки (пишутся в колонку B «Distributor Part Number»).
- Позиция не найдена → в колонках цены пишется «RFQ» (жёлтая заливка).
- Lead Time: «In stock» если стока хватает, иначе «N weeks»; «RFQ», если срок неизвестен.

## Другие скрипты

- `bomtool_to_final.py <экспорт.xlsx> [выход.xlsx]` — конвертер экспорта
  bomtool.oemsecrets.com в тот же итоговый формат.
- `update_bom*.py` — статические архивные скрипты прошлых заявок (данные зашиты в код);
  для новых задач использовать `price_parser.py`.
