# Формат итогового файла

Эталон реализует `src/bomprice/report.py`; ниже — контракт. При расхождении описания
и кода прав код, описание чинится.

## Колонки

Ровно 10 колонок в этом порядке:

| Кол | Заголовок | Откуда |
|---|---|---|
| A | Part Number | артикул из запроса (как распознан / поправлен в превью) |
| B | Distributor Part Number | найденный конкретный артикул производителя, если отличается от A (суффикс, маска, префикс серии) |
| C | Qty for Single BOM | количество из запроса |
| D | Manufacturer | производитель по данным площадки (или из запроса) |
| E | Distributor | DigiKey / Mouser / TME / Newark/Farnell, у агрегаторов — имя продавца |
| F | Minimum Order | MOQ площадки |
| G | Stock | складской остаток |
| H | Lead Time (weeks) | `In stock` / `N weeks` / `уточнить у поставщика` |
| I | Unit Price USD | цена при количестве |
| J | Unit Price RUB | `USD × (курс ЦБ + наценка)` |

A и B стоят рядом намеренно — для визуального сравнения артикулов.

## Оформление

- Заголовок A, C–J: Arial 10 bold, белый текст, заливка `1F4E79`.
- Заголовок B: Arial 10 bold, белый текст, заливка `375623` — тёмно-зелёный выделяет колонку.
- Строки с ценой: чередующаяся заливка `EBF3FB` / `FFFFFF`.
- Строки `RFQ`: заливка `FFF2CC`; в I и J текст `RFQ` bold, цвет `7F4B00`.
- Ячейка B с найденным артикулом: заливка `E2EFDA`.
- Строки, подтверждённые через LLM-контур: заливка `FDE9D9` (персиковый).
- Форматы: USD `#,##0.000`, RUB `#,##0.00`. Все ячейки — Arial 10, тонкая рамка `BFBFBF`.

## Сноска

Объединённая ячейка A:J под таблицей, Arial 9, цвет `595959`, перенос по словам:
`Найдено: N | RFQ: M | Курс USD/RUB (ЦБ + наценка): X | правило цены | список API`,
затем при необходимости: позиции с `MOQ` выше запрошенного количества; число позиций,
подтверждённых LLM-контуром.

## Рубли

`RUB = USD × (курс ЦБ + наценка)`. Наценка по умолчанию `+4` (`config/settings.toml`),
курс — `cbr.ru` (кэш на сутки в `work/fx.json`). Оба значения перекрываются флагами
`--rub-rate` и `--rub-markup`.

## Куда пишется результат и что печатается

Путь задаётся `--output`, по умолчанию `final/BOM_Приложение_1.xlsx`. Превью распознанных
позиций — `превью_позиции.xlsx` в корне проекта (или `--preview-path`).
В консоль в конце — `Готово: <путь>` и `Найдено: N | RFQ: M`; их читает почтовый монитор.
