# Выбор цены и источника

Код: `src/bomprice/select.py` — единственный источник правды; параметры — секция
`[selection]` в `config/settings.toml`.

## Только авторизованные дистрибьюторы

Франшизные API (`kind = "franchise"` в `config/sources.toml`: DigiKey, Mouser, TME,
Newark/Farnell, Arrow) авторизованы по определению. У агрегаторов (`oemsecrets`, `nexar`)
продавец принимается, если его имя содержит одну из подстрок `authorized_sellers`
(DigiKey, Mouser, TME, Farnell/Newark, Arrow/Verical, TTI, Avnet, RS, Future, Heilind,
Rutronik, Bürklin). Брокеры и маркетплейс-перепродавцы отсекаются.

## Порядок выбора

1. Кандидат допускается по [`part-matching.md`](part-matching.md) (артикул + производитель)
   и по продавцу.
2. Цена — из ценового брекета при запрошенном количестве: наибольший брекет с
   `qty ≤ запрошенного`; если все брекеты выше — самый нижний (флаг `min_not_met`).
   Не-USD валюта переводится в USD по курсу дня (`work/fx.json`).
3. Лучший: сначала **наличие** (сток ≥ запрошенного количества), затем минимальная цена,
   при равной цене — больший складской остаток.
4. `MOQ` больше количества из запроса — не отказ: в колонке C остаётся запрошенное
   количество, в F — MOQ, позиция перечисляется в сноске «MOQ выше запрошенного».
5. Найдено несколько написаний одного артикула (суффикс, маска) — после первого прохода
   точные артикулы задаются площадкам повторно (до `resolved_limit`), чтобы точечный
   поиск Mouser/TME/Farnell дал реальный минимум.

## Lead Time

- `In stock`, если стока хватает под запрошенное количество;
- иначе число недель (`N weeks`) из срока площадки (дни округляются вверх до недель);
- срок неизвестен и стока нет — `уточнить у поставщика`.

## Когда позиция становится RFQ

- артикул не распознан либо производитель в запросе не указан;
- ничего не найдено ни на одном источнике;
- найдено только с `partial`/`mismatch` (аналог, другой суффикс не из списка упаковочных)
  или у другого производителя;
- продавец не авторизован;
- нет цены при количестве.

В колонках цены пишется `RFQ`, строка получает жёлтую заливку — оформление в
[`output-format.md`](output-format.md). Причина отказа печатается в консоль рядом с позицией.

## Добивка RFQ-остатка

1. Агрегаторы (`oemsecrets`): позиции с бо́льшим количеством первыми, в пределах суточной
   квоты (`rate.daily`, перекрывается `OEMSECRETS_DAILY_LIMIT`).
2. LLM-контур (`ENABLE_CLAUDE_FALLBACK=true`): headless Claude предлагает полное написание
   артикула и бренд, цены не спрашиваются; подсказка принимается только если по ней API
   дал цену по этому же регламенту. Такие строки помечаются персиковым.

## Валюта

Все цены приводятся к USD; рубли — `USD × (курс ЦБ + наценка)`. Курс и дата фиксируются
в сноске. Подробнее — [`output-format.md`](output-format.md).
