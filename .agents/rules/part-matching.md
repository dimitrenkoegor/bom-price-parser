# Сопоставление позиции с найденным артикулом

Код: общий модуль `src/bomprice/mpn.py` (`match_quality(..., strict=True)`,
`manufacturer_match`), словарь брендов `config/brands.toml`, приёмка — `src/bomprice/select.py`.
Принимаемые качества совпадения — `accept_quality` в `config/settings.toml`.

## Аналоги запрещены

Нельзя заменять позицию аналогом с другими характеристиками: диэлектрик, напряжение,
ёмкость, типоразмер. Позиция без точного совпадения — это `RFQ`, а не «похожее».
В терминах `match_quality`: `partial` и `mismatch` отвергаются всегда.

## Что принимается

| Качество | Когда | Пример |
|---|---|---|
| `exact` | совпадение с точностью до разделителей, регистра, десятичной запятой/точки, кириллических двойников букв | `Q 10,240-SS3` = `Q10.240-SS3` |
| `mask` | в запросе маска регламента | ниже |
| `suffix` | отличие только в упаковочном хвосте из `PACKAGING_TAILS` — у кандидата, у запроса или у обоих | `CR0805-JW-390E` → `CR0805-JW-390ELF`, `C5750X7R1H106KT` → `C5750X7R1H106K230KB` |
| `prefix_series` | кандидат дополнен 1–2-буквенным префиксом серии, запрошено ≥ 6 знаков, хвост пуст или упаковочный | `0805-FX-1503` → `CR0805-FX-1503ELF` |

Типичные упаковочные суффиксы: `T`, `TR`, `CT` (лента), `K` (bulk), `L`, `LF`, `ELF`, `GLF`
(RoHS), `PBF`, `TRPBF`, `230KB`. Незнакомый суффикс в строгом режиме считается
`partial` — проверить по даташиту и добавить в `PACKAGING_TAILS`, а не предполагать.
Найденный конкретный артикул пишется в колонку B, в колонке A остаётся исходный из запроса.

## Маска `x` / `Xx` / `XX`

- строчный `x` (или кириллическая `х`) в конце, один и более — любой суффикс: `3313J-1-104x`;
- хвост из двух и более заглавных `X` — маска: `DLC…CXX` → `DLC…C2TE3`;
- смешанный хвост `Xx` — маска: `DLC70B8R2CW501Xx` → `DLC70B8R2CW501XT`;
- строчный `x` в середине — ровно один любой символ: `TPSE477K010x0200` → `TPSE477K010R0200`;
- одиночная заглавная `X` — часть реального артикула (`EXB28V220JX`), не маска.

Площадке задаётся база без маски (вариант `base`), маска отбирает из ответа.

## Производитель

- Искать только у производителя, указанного в запросе. Не подменять его другим, даже когда
  характеристики совпадают.
- Производитель не указан — это `RFQ`, а не подбор аналога.
- Совпадение считается с учётом словаря: алиасы (`Avago` = `Broadcom`, `ST Micro` =
  `STMicroelectronics`) и поглощения (`Linear Technology` = `Analog Devices`, `Cypress` =
  `Infineon`, `Fujitsu` (реле) = `FCL Components`) — секции `[brands]` и `[acquired_by]`
  в `config/brands.toml`. Неизвестный бренд из запроса сравнивается буквально.
- Площадка не вернула производителя (oemsecrets) — цена принимается только при `exact`.

## Составная ячейка «тип изделия + MPN + бренд»

Разбор автоматический (общий `mpn.py`): русское слово-тип снимается, бренд ищется по словарю
в любой позиции строки и в скобках (`Вилка 44914-0801 (Molex)`), артикул выбирается
скорингом токенов. Префиксы `Q`/`O`, пробелы в составных кодах (`16 MMCX-50-2-13/111 OE`),
запятые, точки, `/` и дефисы сохраняются. Кириллические единицы после числа
(`КОМ` → `K`, `КГЦ` → `kHz`) нормализуются только когда настоящего артикула в строке нет.
Отечественные обозначения с кириллицей (`КР580ВМ80А`) не латинизируются.

Колонка «Производитель» в запросе имеет приоритет над брендом из текста.

## Позиция без явного партномера

В запросе только описание → в превью артикул пуст (красный). Человек вписывает точный
артикул, сверив **все** характеристики по сайту производителя, и запускает
`--from-preview`. Скрипт артикул по описанию не подбирает; не вписан — `RFQ`.
