# Почтовый монитор: письмо с BOM → ответ с ценами

`mail_monitor.py` — автономный демон без внешних сервисов. Проверяет ящик по IMAP,
письмо от разрешённого отправителя с командой («найти цены», «просчитать BOM», «дай
цены», «прайс») и вложением `.xlsx/.xlsm/.txt` прогоняет через `price_parser.py`
и отвечает готовым файлом.

## Запуск и остановка

| Действие | Как |
|---|---|
| один цикл, без отправки | `python mail_monitor.py --once --dry-run` |
| демон в фоне | `START_MAIL.bat` (пишет `monitor.pid`, логи `monitor.log`, `monitor.out.log`) |
| остановить | `STOP_MAIL.bat` (флаг `STOP_MONITOR`, через 5 с — принудительно) |
| автозапуск при входе в Windows | `INSTALL_AUTOSTART.bat` — пишет значение `bom_mail_monitor` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` с абсолютным путём к проекту (старый `bom_mail_monitor.bat` из Startup удаляет); после переноса папки запустить заново. `UNINSTALL_AUTOSTART.bat` удаляет оба |

Один ящик — один монитор: второй экземпляр будет отбирать письма.

## Что происходит с письмом

1. Отправитель проверяется по `ALLOWED_SENDERS` (через `;`, допустим `@домен`).
2. Тема и тело — по триггеру. Нет команды → письмо помечается просмотренным, ничего не делается.
3. Вложения сохраняются в `jobs_mail/<дата-хэш>/source/`, каждое прогоняется:
   `price_parser.py --input … --output … --preview-path … --yes` (таймаут 30 мин,
   лог `parser_<имя>.log`).
4. Санити-проверки перед отправкой: у каждой найденной позиции цена — число > 0; если
   найдено 0 и ≥ 60 % позиций отвергнуты с «производитель не указан» — это сбой
   распознавания колонок, а не RFQ: письмо клиенту не уходит, служебное письмо себе.
5. RFQ-остаток пишется в `jobs_mail/<job>/rfq_list.txt`; при `ENABLE_CLAUDE_FALLBACK=true`
   headless Claude дополнительно пишет подсказки в `fallback.json`.
6. `HOLD_ON_RFQ=true` — при любом RFQ ответ клиенту **придерживается**, уходит письмо себе
   с путём к файлу; человек проверяет и отправляет вручную.
7. Иначе `SEND_ENABLED=true` — ответ `Re:` с вложениями по SMTP_SSL.
8. Письмо помечается `\Seen`; дедупликация по хэшу Message-ID в `mail-state.json`.

## Переменные .env

`MAIL_IMAP_HOST`, `MAIL_IMAP_MAILBOX`, `MAIL_USER`, `MAIL_PASSWORD` (пароль приложения),
`MAIL_SMTP_HOST`, `MAIL_SMTP_PORT`, `ALLOWED_SENDERS`, `POLL_SECONDS` (мин. 30),
`SEND_ENABLED`, `HOLD_ON_RFQ`, `ENABLE_CLAUDE_FALLBACK`. Полный список с пояснениями —
`.env.example`. Без `MAIL_USER`/`MAIL_PASSWORD`/`ALLOWED_SENDERS` монитор не стартует.

## Контракт с парсером

Монитор парсит stdout парсера: строки `Найдено: N | RFQ: M` и `RFQ: производитель не указан`,
и колонки итогового xlsx (A — артикул, C — количество, E — дистрибьютор, I — цена).
Менять формат вывода или порядок колонок — значит сломать монитор.
