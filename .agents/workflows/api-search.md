# Основной маршрут: поиск через API дистрибьюторов

Единственный источник цены. Что не закрылось — `RFQ`; браузерной доборки нет.

## Главная команда

```bash
python price_parser.py --input "<запрос.xlsx>" --output "final/<имя_результата>.xlsx" --yes
```

- `--input` — Excel-запрос. Шапка и колонки распознаются автоматически: Наименование /
  Условное обозначение / Количество / Производитель. Поддерживается и `.txt`
  (строки `PARTNUMBER QTY`).
- `--output` — путь итогового файла, по умолчанию `final/BOM_Приложение_1.xlsx`.
- `--yes` — пропускает интерактивное подтверждение превью.
- `--rub-rate 80 --rub-markup 4` — курс и наценка вручную.

Проверка одной позиции:

```bash
python price_parser.py --once <PN> <QTY> --manufacturer <бренд> --yes
```

Тесты:

```bash
PYTHONPATH=. python -m unittest tests.test_price_parser
```

## Что делает скрипт

1. Распознаёт позиции из Excel и пишет превью `превью_позиции.xlsx`; при `--yes` не ждёт
   правок. Разбор составных ячеек и нормализация —
   [`../rules/part-matching.md`](../rules/part-matching.md).
2. Ищет цены по четырём API (DigiKey, Mouser, TME, Newark/Farnell) и выбирает предложение
   по [`../rules/price-selection.md`](../rules/price-selection.md).
3. LLM-контур предлагает написание артикула для нераспознанных строк. Цену модель дать не
   может: строка заполняется только после подтверждения через API и красится персиковым.
4. Пишет стилизованный xlsx по [`../rules/output-format.md`](../rules/output-format.md).
5. Печатает итог: `Найдено: N | RFQ: M` и путь к файлу — эти две строки и надо парсить для
   отчёта, а не пересчитывать книгу заново.

Ключи, домены и зависимости — [`../references/environment.md`](../references/environment.md).
