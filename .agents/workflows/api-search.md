# Основной маршрут: поиск через API дистрибьюторов

Это канонический способ. Браузерная доборка применяется только там, где этот маршрут не
дал результата — см. [`browser-fallback.md`](browser-fallback.md).

## Главная команда

```bash
python price_parser.py --input "<запрос.xlsx>" --output "final/<имя_результата>.xlsx" --yes
```

- `--input` — Excel-запрос. Шапка и колонки распознаются автоматически: Наименование /
  Условное обозначение / Количество / Производитель. Поддерживается и `.txt`
  (строки `PARTNUMBER QTY`).
- `--output` — путь итогового файла, по умолчанию `final/BOM_Приложение_1.xlsx`.
- `--yes` — **обязателен для агентов**: пропускает интерактивное подтверждение превью.
  Без него скрипт остановится на `input()` и зависнет.
- `--rub-rate 80 --rub-markup 4` — курс и наценка вручную.

## Где лежат входные файлы

- `start/запрос.xlsx`, `start/Приложение №1.xlsx` — сам BOM-запрос. Из него берутся только
  Part Number, Qty и Manufacturer.
- `start/BOM_Приложение_1_XXXX.xlsx` — эталон оформления: структура, стили, шрифты.
  Скрипт воспроизводит его сам, отдельно открывать эталон не нужно.
- Результат по умолчанию — `final/BOM_Приложение_1.xlsx`.

Проверка одной позиции:

```bash
python price_parser.py --once <PN> <QTY> --manufacturer <бренд> --yes
```

## Что делает скрипт

1. Распознаёт позиции из Excel и пишет превью `превью_позиции.xlsx`; при `--yes` не ждёт
   правок. Разбор составных ячеек и нормализация — [`../rules/part-matching.md`](../rules/part-matching.md).
2. Ищет цены по четырём API и выбирает предложение по
   [`../rules/price-selection.md`](../rules/price-selection.md).
3. Пишет стилизованный xlsx по [`../rules/output-format.md`](../rules/output-format.md).
4. Печатает итог: `Найдено: N | RFQ: M` и путь к файлу — эти две строки и надо парсить
   для отчёта, а не пересчитывать книгу заново.

## Другие скрипты

- `bomtool_to_final.py <экспорт.xlsx> [выход.xlsx]` — конвертер экспорта
  `bomtool.oemsecrets.com` в тот же итоговый формат.
- `update_bom*.py` — статические архивные скрипты прошлых заявок с зашитыми в код данными.
  Для новых задач не использовать.

Ключи, домены и зависимости — [`../references/environment.md`](../references/environment.md).
