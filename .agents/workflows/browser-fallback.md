# Запасной маршрут: ручная доборка браузером

Применяется только к позициям, которые не закрыл API-маршрут
([`api-search.md`](api-search.md)): нет ключей, источник молчит, позиция ушла в `RFQ`,
а пользователь просит добрать вручную.

Правила выбора цены и сопоставления артикула те же, что и на основном маршруте:
[`../rules/price-selection.md`](../rules/price-selection.md),
[`../rules/part-matching.md`](../rules/part-matching.md).
Формат результата тот же: [`../rules/output-format.md`](../rules/output-format.md) —
десять колонок, включая рублёвую.

## Шаг 1. oemsecrets через браузер

Открывать `https://www.oemsecrets.com/compare/АРТИКУЛ` в Claude in Chrome.

- Данные грузятся асинхронно: после перехода ждать 4–6 секунд, только потом читать текст.
- Открывать по одной вкладке с паузой 3–5 секунд между переходами, иначе блокирует
  Cloudflare.
- `Loading Search Results` держится дольше 10 секунд — считать заблокированным, идти к шагу 2.
- `No Distributor Results Found` — позиция получает `RFQ`, идти к шагу 2.
- Сайт показывает цены в EUR — пересчитать в USD по актуальному курсу и зафиксировать курс
  в сноске.

## Шаг 2. Прямые страницы дистрибьюторов

Здесь обычная загрузка страницы работает:

- DigiKey: `https://www.digikey.com/en/products/detail/АРТИКУЛ`
- Mouser: `https://www.mouser.com/ProductDetail/АРТИКУЛ`
- TTI: `https://www.tti.com/content/ttiinc/en/apps/part-detail.html?partsNumber=АРТИКУЛ`

## Шаг 3. Позиция не найдена нигде

Вписать `RFQ`. Известные проблемные производители:

- **Dalicap** (серия DLC70B) — только через `dalicap.com`;
- **Hitano** (серия EXR) — только через `hitano.com.tw`;
- **Jamicon** (серия TKR) — только у региональных дистрибьюторов.

## Что заведомо не работает

- Обычная загрузка страницы oemsecrets — возвращает пустую JS-оболочку без данных, нужен
  именно браузер.
- Параллельные запросы к oemsecrets (больше одной вкладки одновременно) — блокирует
  Cloudflare.
- Чтение сразу после перехода — oemsecrets не держит данные в DOM, нужно дождаться XHR.
