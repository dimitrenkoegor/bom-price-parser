# Браузерный каскад по BOM-инструментам

Закрывает RFQ-остаток итогового xlsx через BOM-инструменты площадок,
**каскадом**: каждая следующая площадка получает только то, что не закрыла
предыдущая. Порядок: `oemsecrets` -> `octopart` -> `findchips` -> `trustedparts`.

## Цикл на каждую площадку

1. ```
   python browser_bom.py export --site <site> --result "<итоговый.xlsx>"
   ```
   Запомнить путь CSV и число позиций из вывода.
   **Если позиций 0 — каскад закончен, остановиться.**
2. Браузерная нога в Claude in Chrome — по инструкции `references/<site>.md`.
3. ```
   python browser_bom.py merge --site <site> --result "<итоговый.xlsx>" --export "<скачанный>" --dry-run
   ```
   Прочитать таблицу принято/отклонено. Проверить: нет брокеров, нет аналогов,
   счётчик «вне остатка» не задевает уже найденные строки.
4. Если всё верно — повторить без `--dry-run`.
5. ```
   python browser_bom.py status --result "<итоговый.xlsx>"
   ```
   Остался RFQ -> следующая площадка, шаг 1.

## Жёсткие правила

- **Никогда не править итоговый xlsx или CSV руками.** Цена входит только
  через `merge` — там шлюз валидации по регламенту.
- **Никогда не перепроверять позицию, которой нет в файле выгрузки.**
  Выгрузка и есть контракт каскада: что не в ней — уже найдено или без
  производителя (RFQ навсегда).
- **Одна вкладка за раз.** 3–5 с паузы между навигациями, 4–6 с после
  navigate до чтения страницы — параллельные вкладки ловят Cloudflare
  (регламент, §«Что не работает»).
- Перед экспортом выставить валюту **USD** и ограничить настройки
  дистрибьюторов авторизованным списком (DigiKey, Mouser, Arrow, TTI, TME,
  Avnet, Newark/Farnell, Future, Heilind, RS, Rutronik).
- `web_fetch` на oemsecrets возвращает JS-оболочку — только браузер.
- Экспорт oemsecrets echo-only (нет колонки подобранного MPN) — merge для
  него запускать с `--trust-echo`. Для остальных площадок сначала пробовать
  без него.
- **Остановиться и спросить пользователя**, если площадка требует
  регистрацию, логин, платёжные данные или принятие условий/ToS.
  Не регистрироваться, не принимать условия, не решать CAPTCHA.

## Ошибки и блокировки

См. `references/troubleshooting.md`. Кратко: Cloudflare «Loading Search
Results» >10 с — бросить площадку, идти к следующей; «No Distributor Results
Found» — вся пачка RFQ для площадки, идти дальше; частичный экспорт — merge
идемпотентен, повторное слияние надмножества безопасно.

## Инструменты Chrome

Deferred — загрузить **одним** вызовом ToolSearch:
`mcp__claude-in-chrome__tabs_context_mcp, navigate, computer, read_page, find,
form_input, file_upload, get_page_text`.
