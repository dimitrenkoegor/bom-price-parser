# Ошибки и блокировки

## Cloudflare

- «Loading Search Results» висит дольше 10 с — площадка заблокировала.
  **Не ретраить, не открывать параллельные вкладки** (станет хуже).
  Бросить площадку, перейти к следующей в каскаде; текущая выгрузка CSV
  остаётся валидной для неё.
- Профилактика: одна вкладка, 3–5 с между навигациями, 4–6 с после
  navigate до чтения страницы.

## «No Distributor Results Found»

Вся пачка — RFQ для этой площадки. Скачивать нечего, `merge` не нужен,
переходить к следующей площадке (выгрузка та же).

## Частичный экспорт (скачался не весь список)

`merge` идемпотентен: принимает только строки, которые всё ещё RFQ.
Повторное слияние надмножества безопасно — можно скачать полный экспорт
и слить ещё раз.

## BrowserExportFormatError при merge

Формат экспорта площадки не разобрался. В тексте ошибки — буквальные
заголовки файла и готовая строка для `SITES['<site>']['aliases']` в
`browser_bom.py`. Добавить синоним, повторить merge. Копию экспорта
положить в `final/browser/samples/` и закрепить фикстурой в тестах.

## Отказы валидации (в выводе merge)

- `no_manufacturer` / `wrong_manufacturer` — производитель пуст или чужой;
  так и должно быть: аналоги запрещены.
- `analog_mpn` — площадка подобрала другой артикул; не принимается.
- `broker` / `unknown_distributor` — дистрибьютор вне белого списка.
  Если это реально крупный франчайзинговый дистрибьютор — расширить
  `OEMSECRETS_AUTHORIZED` в `price_parser.py` осознанно.
- `bad_currency` — валюта не определилась; передать `--currency EUR`
  (или USD) явно, если валюта площадки известна.
- `echo_only` — нет колонки подобранного MPN; для oemsecrets это норма,
  запускать с `--trust-echo`.

Полная история решений — `final/browser/cascade.jsonl` (append-only журнал).
