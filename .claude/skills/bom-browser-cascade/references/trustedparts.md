# TrustedParts

- URL: `https://www.trustedparts.com/`
- Площадка ECIA: только авторизованные франчайзинговые дистрибьюторы
  (по определению соответствует регламенту).

## Процедура (уточнить при первом прогоне)

1. Открыть URL, найти BOM tool / список загрузки.
2. Загрузить CSV, сопоставить колонки.
3. Валюта **USD**.
4. Экспортировать результат.

## Формат экспорта

Не верифицирован (заглушка в `SITES`). При BrowserExportFormatError —
добавить синонимы в `SITES['trustedparts']['aliases']`, копию экспорта —
в `final/browser/samples/`.
